关于博客

本博客基于 Jekyll 构建，部署在 GitHub Pages 上（域名：fuoins.github.io）， 支持 Markdown 语法和数学公式渲染（KaTeX），并针对移动端做了深度适配。 博客内容主要涵盖编程基础、算法设计、数学建模、开源工具使用等方向， 旨在记录学习过程，分享技术心得，同时也希望能帮助到更多正在学习的开发者。

博客的核心特性包括：

  • 全终端适配：完美支持手机、平板、电脑等不同尺寸设备
  • 数学公式支持：基于 KaTeX 实现高性能的数学公式渲染，支持自动换行
  • 简洁美观：轻量化设计，无冗余内容，专注阅读体验
  • 开源可扩展：基于 Jekyll 生态，可灵活扩展功能

如果你有任何问题或建议，欢迎通过邮箱或 GitHub 联系我，我会尽力解答。 同时，也欢迎大家对博客源码提出改进意见，共同完善这个博客系统。
