### 博客技术架构

本站采用**无插件轻量化架构**，完全基于 Jekyll 原生功能 + 原生 Web 技术实现，保证加载速度与稳定性：

| 技术领域 | 核心技术 | 选择理由 |
|----------|----------|----------|
| 静态站点生成 | Jekyll 4.x | 与 GitHub Pages 深度兼容，部署成本为零 |
| 前端页面构建 | 原生 HTML5/CSS3/JavaScript | 无框架依赖，体积小、加载快 |
| 样式设计 | CSS 变量 + 响应式布局 | 统一管理配色，全端适配 |
| 数学公式渲染 | MathJax 3.x | 支持 LaTeX 语法，移动端自动换行 |
| 部署平台 | GitHub Pages + Cloudflare | 免费稳定，支持自定义域名 |

### 常见问题

| 问题现象 | 解决方案 |
|----------|----------|
| MathJax 公式不显示 | 检查公式语法，确认脚本加载，刷新页面重试 |
| 样式修改后不生效 | 清除浏览器缓存（CSS 已带版本号防缓存） |
| 移动端排版异常 | 使用系统浏览器最新版本访问 |
