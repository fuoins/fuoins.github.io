二、填空题

  3. 若在实体R的诸属性中，属性A不是R的主键，却是另一个实体S的主键，则称A为R的外键。

  6. 用树型结构表示实体类型及实体间联系的数据模型称为层次模型。
  7. 在数据库中，当某个实际值暂时未知或无意义时，我们将其表示为null。
  8. 关系数据库中的投影操作是指从关系中抽出特定字段。
  9. 关系R与S的属性个数分别为r和s，则R×S的属性个数为r+s。

  14. 在SQL中，对修改基本表结构的命令关键字为 alter TABLE。

  16. 角色是一组系统权限的集合，用它管理权限可以简化授权的过程。
  17. 学生社团可以接纳多名学生参加，但每个学生只能参加一个社团，从社团到学生之间的联系类型是 一对多。

  29. 判断一个并发调度是否正确，可用可串行化概念来衡量。
  30. 并发控制的主要技术有封锁、时间戳和乐观控制法。
  31. 在有多个事务需要执行时，如果利用分时的方法，同时处理多个事务，则称事务是并行或并发执行。

三、问答题

  1. 数据库管理系统有哪些主要功能？
    答：(1)数据定义功能。提供数据定义语言(DDL)，定义数据库中的数据对象。(2)数据组织、存储和管理(3)数据操纵功能。提供数据操纵语言(DML)，实现对数据库的基本操作(查询、插入、删除和修改)。(4)数据库的事务管理和运行管理。保证数据的安全性、完整性、多用户对数据的并发使用、发生故障后的系统恢复。(5)数据库的建立和维护功能。
  2. 数据库系统阶段有哪些特点。
    答：(1)数据结构化;(2)数据的共享度高，冗余度低，易扩展;(3)数据独立性高;(4)数据由DBMS统一管理和控制.
  3. 关系模型的完整性规则有哪些，并简要解释每条规则。
    答：实体完整性、参照完整性和用户自定义完整性。
    实体完整性规则：若属性A是基本关系R的主属性，则A不能取空值；
    参照完整性规则：若属性F是关系R的外码，它与关系S的主码相对应，则对于R中的每个元组在F上的值必须为空值，或者等于S中某个元组的主码值；
    用户自定义完整性规则：反映某一具体应用所涉及的数据必须满足的语义要求。
    基本关系具有以下6条性质：
    ①列是同质的（Homogeneous）每一列中的分量是同一类型的数据，来自同一个域。
    ② 不同的列可出自同一个域。其中的每一列称为一个属性，不同的属性要给予不同的属性名。
    ③ 任意两个元组的候选码不能完全相同。
    ④ 行的顺序无所谓，行的次序可以任意交换。
    ⑤ 列的顺序无所谓，即列的次序可以任意交换。
    ⑥ 分量必须取原子值，即每一个分量都必须是不可分的数据项。
  4. 简述视图的优点（作用）。
    答：（1）视图能够简化用户的操作。（2）视图使用户能以多种角度看待同一数据。（3）视图对重构数据库提供了一定程度的逻辑独立性。（4）视图能够对机密数据提供安全保护。（5）适当的利用视图可以更清晰的表达查询。
  5. 简述数据库安全性控制的常用技术。
    答：（1）用户标识和鉴别（2）存取控制（3）视图机制（4）审计（5）数据加密
  6. 系统进行参照完整性检查时，如果发生不一致的情形，系统可以采用哪些策略来加以处理？
    (1)拒绝执行(2)级联操作(3)设置为空值
  7. 数据库概念结构设计有哪些常用方法？
    （1）自顶向下（2）自底向上（3）逐步扩张（4）混合策略
  8. 简述数据库设计的基本步骤。
    答：（1）需求分析。（2）概念结构设计。（3）逻辑结构设计。（4)物理结构设计。（5）数据库实施。（6)数据库的运行和维护。
  9. 试述事务的概念及事务的4个特性。
    答：所谓事务是用户定义的一个数据库操作序列，这些操作要么全做要么全不做，是一个不可分割的工作单位。
    事务具有4个特性：
    （1）原子性：事务是数据库的逻辑工作单位，事务中包括的诸操作要么都做，要么都不做。（2）一致性：事务执行的结果必须使数据库从一个一致性状态变到另一个一致性状态。（3）隔离性：一个事务的执行不能被其他事务干扰。（4）持续性：事务一旦提交，它对数据库的改变就应该是永久性的。
  10. 数据库运行中可能产生的故障有哪几类？哪些故障影响事务的正常执行？哪些故障破坏数据库数据？
    （1）事务内部的故障；（2）系统故障；（3）介质故障；（4）计算机病毒。
    事务故障、系统故障和介质故障影响事务的正常执行；介质故障和计算机病毒破坏数据库数据。
  11. 简述两段锁协议的含义及作用。
    答：两段锁协议是指所有事务必须分两个阶段对数据项加锁和解锁。
    第一阶段是获得封锁：在对任何数据进行读、写操作之前，首先要申请并获得对该数据的封锁。
    第二阶段是释放封锁：在释放一个封锁之后，事务不再申请和获得任何其他封锁。
    作用：实现并发调度的可串行性，从而保证调度的正确性。

  1. 画出系统的E-R图。
  2. 将E-R图转换为关系模型。指出每个关系模式的码（主码用下划直线标出，外码用下划波浪线标出）。
答案：

（四）关系模式范式分析

题干：分析下列关系模式最高属于第几范式，并解释其原因。
  1. R（A，B，C，D）， F={ B→D，AB→C }
  2. R（A，B，C）， F={ A→B，B→A，A→C }
  3. R（A，B，C，D），F={ A→C，CD→B }
  4. R(A，B，C)，F={C→B，B→A}
答案：
  1. R（A，B，C，D）， F={ B→D，AB→C }

    最高范式：1NF

    原因：

    • 首先满足1NF：所有属性均为原子值，不可再分；
    • 候选码为AB（AB能唯一决定所有属性，且无真子集能决定全部属性）；
    • 存在非主属性D对候选码AB的部分函数依赖（B→D，B是AB的真子集），不满足2NF；
    • 无其他更高级范式的满足条件，故最高为1NF。
  2. R（A，B，C）， F={ A→B，B→A，A→C }

    最高范式：BCNF

    原因：

    • 候选码为A和B（A与B相互函数决定，二者均可单独唯一决定C）；
    • 满足2NF：无部分函数依赖（非主属性C完全依赖于任意一个候选码）；
    • 满足3NF：无传递函数依赖（C直接依赖于候选码，无中间属性传递依赖）；
    • 满足BCNF：所有函数依赖的决定因素均为候选码（A、B均是候选码），故最高为BCNF。
  3. R（A，B，C，D），F={ A→C，CD→B }

    最高范式：1NF

    原因：

    • 满足1NF：所有属性均为不可再分的原子值；
    • 候选码为ACD（ACD能唯一决定所有属性，其任意真子集无法决定全部属性）；
    • 存在非主属性C对候选码ACD的部分函数依赖（A→C，A是ACD的真子集），不满足2NF；
    • 因此该关系模式最高属于1NF。
  4. R(A，B，C)，F={C→B，B→A}

    最高范式：2NF

    原因：

    • 候选码为C（C可通过传递依赖决定B和A，且无任何真子集能决定全部属性）；
    • 满足2NF：无部分函数依赖（非主属性A、B均完全依赖于候选码C）；
    • 存在非主属性A对候选码C的传递函数依赖（C→B，B→A，A间接依赖于C），不满足3NF；
    • 故该关系模式最高属于2NF。
