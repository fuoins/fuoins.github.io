功能简介

多书库阅读器，支持导入多本小说，每本书独立保存阅读进度和设置。

主要功能：

  • 内置书籍：默认包含同目录下的《蛊真人》（123.txt）
  • 多书管理：导入、切换、删除书籍
  • 独立设置：每本书单独保存字体、背景等设置
  • 进度记忆：自动记录每本书的阅读位置
  • 大文件支持：使用IndexedDB存储，支持GB级文件

快捷键说明：

快捷键 功能
← → 上一页/下一页（保留两行上下文）
↑ ↓ 上滚/下滚（微调）
PgUp PgDn 上一页/下一页（整页）
Ctrl+← → 上一章/下一章
Space 下滚一屏
Esc 关闭侧边栏
F1 显示/隐藏此帮助

使用提示：

  • 点击左上角菜单按钮打开侧边栏
  • 默认内置《蛊真人》，无需手动导入
  • 每本书的设置和进度都是独立的
  • 本地使用时需通过服务器打开（如VS Code Live Server）
